# specs/

This directory contains implementation-independent product specification
material for Compare-DirectoryTree.

- **`Compare-DirectoryTree-Spec.md`** is the single authoritative current
  behavioral specification. All implementations and tests must conform to
  it. The specification is aligned with software releases rather than
  having an independent version: the state of the specification at a
  release tag defines the behavior of that release.
- **`speclets/`** contains focused, proposed or in-progress design changes.
  Once a speclet is accepted and incorporated into the authoritative
  specification, it is normally deleted. Git history and release tags
  preserve prior states and development history, so no separate archive is
  kept.
- **`CHANGELOG.md`** (at the repository root) provides the curated history
  of notable released and unreleased changes.
